# OctoAcme Project Management Documentation

A concise index and entry point for OctoAcme's project management processes. OctoAcme follows a customer-first, iterative approach with clear ownership and a focus on measurable outcomes. Each project has a named Project Manager (PM) and Product Manager (PdM), and teams deliver in small, testable increments while using data to guide decisions. The documentation in this folder explains lifecycle stages, roles, workflows, communication cadence, and QA/release practices.

## Quick Start
- New project? Start with: docs/octoacme-project-initiation.md
- Planning phase? See: docs/octoacme-project-planning.md
- In execution? Reference: docs/octoacme-execution-and-tracking.md
- Preparing to release? Follow: docs/octoacme-release-and-deployment.md
- After release? Run: docs/octoacme-retrospective-and-continuous-improvement.md

## How to use these docs
- PM / PdM: start with the Project Management Overview and Project Initiation, maintain the Project Charter in the project repo.

- Stakeholders: consult Risk Management & Communication for weekly status templates and escalation paths.
